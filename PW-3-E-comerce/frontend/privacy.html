Aviso de privacidade

Como usamos seus dados

Os dados informados no checkout são usados para identificar e cumprir o pedido e para processar o pagamento. CPF e RG são cifrados antes de serem armazenados. Os dados de cartão são processados pelo componente oficial do Mercado Pago e não são armazenados nesta loja.

Para processar uma compra, o Mercado Pago recebe os dados mínimos do pagador exigidos pelo fluxo de pagamento. RG, data de nascimento, turma e modalidade não são enviados pelo adaptador da loja.

Os pedidos ficam em um banco de dados privado, com acesso operacional restrito. Os prazos de retenção, dados completos do controlador e canal de contato para solicitações devem ser preenchidos pelo responsável pelo negócio antes da abertura pública do checkout.
